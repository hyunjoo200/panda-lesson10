# 중국어 탐험대 · 10차시 — 판다네 집, 我喜欢! 💖

판다네 집의 방 6개에서 **우리 반 밸런스 게임**을 해요. (약 6~7분, 채점 문제 8개)
1. ⚡ VS! 두 가지 중 좋아하는 것을 5초 안에 골라요 (정답 없음, 빨리 고르면 번개 코인).
2. 🔮 "우리 반 친구들은 뭘 더 많이 골랐을까?" 예측 → 맞히면 코인 +2, 별 +20.
3. 📊 우리 반 결과가 **실시간 막대**로 나와요. Firebase에는 이름 없이 보기마다 "몇 명"만 저장해요.
4. ✏️ 판다의 문제 (아래 표). 모은 코인으로 🎰 **판다 뽑기**를 돌려 모자·안경·소품을 모으고 입혀요.
방 두 개를 마치면 **깜짝 손님(엄마 판다)**이 찾아와요. 끝 화면에서 취향 프로필 + 우리 반 전체 결과를 볼 수 있어요.
온라인 저장이 꺼져 있으면 "판다 마을 친구들 예시 숫자"로 보여 줘요(실제 반 결과가 아니라고 화면에 표시돼요).

**⚠️ 이번 차시부터 Firebase 보안 규칙을 한 번 바꿔야 우리 반 결과가 보여요.** firestore-rules.txt 전체를 Firebase 콘솔 → Firestore → 규칙에 붙여 넣고, teacher@example.com 부분을 선생님 이메일로 다시 바꾼 뒤 '게시'를 누르세요.

| 방 | 고르는 것 (정답 없음) | 문제 |
| --- | --- | --- |
| 🛋️ 거실 | 취미: 听音乐 / 画画 | 我 喜欢 (고른 것) 순서 맞추기 — 想·吃 조각이 섞여 있어요 |
| 🧸 내 방 | 동물: 熊猫 / 猫 | 你喜欢什么？를 듣고 뜻 고르기 (뭐 좋아해? / 뭐 먹고 싶어? / 이름이 뭐야?) |
| 📚 공부방 | 과목: 数学 / 体育 / 美术 | 사진 보고 美术 고르기 |
| 🪟 베란다 | 날씨: 晴天 / 雪天 / 雨天 | 我喜欢雪天。 듣고 사진 고르기 |
| ⚽ 마당 | 운동: 踢足球 / 打篮球 / 打羽毛球 / 游泳 | 我喜欢 ___ 足球 — 踢 / 打 고르기 |
| 🍳 주방 | 음식: 饺子 / 麻辣烫 | ① 배고플 때: 我想吃○○ vs 我喜欢○○ (헷갈리기 문제) ② 냉장고 속 9차시 음식 锅贴 |
| 🔔 깜짝 손님 | 사람: 妈妈 vs 朋友 | 我是谁？ 듣고 妈妈 / 猫 / 熊猫 중 고르기 |

끝나면 **나의 취향 프로필**(고른 7가지 + 我喜欢… 문장 듣기)과 **낱말 도감**이 나와요.
선생님 화면(`teacher.html`, 차시 `lesson10`)에서 학생이 고른 취향을 볼 수 있어요.

## GitHub에 올릴 파일 (새 저장소, 예: panda-lesson10)
zip을 풀면 생기는 폴더 **안의 파일들**(img 폴더 포함)을 올려 주세요. `firebase-config.js`는 이전 차시 것을 복사해 붙여 넣어요.
